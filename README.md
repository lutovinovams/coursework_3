# Курсовая работа: Веб-приложение сервиса рассылок сообщений

Веб-приложение на базе фреймворка **Django 6.1**, предназначенное для управления клиентами, шаблонами сообщений и автоматизации процесса рассылок с динамическим расчетом статусов и ведением подробного журнала логов.

## 🚀 Стек технологий
* **Backend:** Python 3.14, Django 6.1
* **Database:** SQLite 3
* **Frontend:** HTML5, CSS3, Bootstrap 5 (Local/CDN)
* **Инструменты:** Git, python-dotenv, LocMemCache

---

## 🛠️ Реализованный функционал

### 1. Управление клиентами и сообщениями (CRUD)
* Полноценный интерфейс для добавления, просмотра, изменения и удаления получателей (модель `Client`).
* Управление текстовыми шаблонами писем с указанием темы и тела сообщения (модель `Message`).

### 2. Сервис управления рассылками
* Контроль интервалов работы рассылок (поля `start_time` и `end_time`) со встроенной валидацией дат.
* **Динамический пересчет статусов** (`Создана`, `Запущена`, `Завершена`) «на лету» при просмотре страниц (`get_object` и `get_queryset`).
* Возможность принудительной ручной инициации отправки писем через UI-интерфейс.

### 3. Регистрация и разграничение прав доступа
* Кастомная модель пользователя с уникальным идентификатором по Email.
* Механизм регистрации с подтверждением учетной записи через верификационную ссылку.
* Функция восстановления (сброса) пароля с автоматической генерацией.
* **Ролевая модель доступа:**
  * **Пользователь:** управляет исключительно своими рассылками, клиентами и видит только свою персональную статистику.
  * **Менеджер (группа `Manager`):** имеет права на сквозной просмотр всех данных, блокировку аккаунтов пользователей и принудительное отключение активных рассылок. Менеджер ограничен в правах на редактирование или удаление чужого кода.

### 4. Статистика, отчеты и кэширование
* Наглядные аналитические карточки на главном экране приложения.
* Сбор информации о количестве успешных/неуспешных попыток отправки сообщений (модель `Log`).
* Оптимизация производительности с помощью встроенного клиентского и серверного кэширования `LocMemCache`.

## 💻 Инструкция по локальному развертыванию

1. **Клонировать репозиторий и перейти в папку проекта:**
   ```bash
   git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
   cd coursework_3
   ```

2. **Cоздать и активировать виртуальное окружение:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

3. **Установить необходимые зависимости:**
   ```bash
   pip install django python-dotenv
   ```

4. **Выполнить миграции для сборки структуры базы данных:**
   ```bash
   python manage.py makemigrations users
   python manage.py makemigrations main
   python manage.py migrate
   ```

5. **Создать учетную запись Администратора (Суперпользователя):**
   ```bash
   python manage.py createsuperuser
   ```

6. **Запустить локальный веб-сервер:**
   ```bash
   python manage.py runserver
   ```
   Приложение станет доступно в браузере по адресу: `http://127.0.0`
